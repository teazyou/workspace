# Repository Index — `~/workspace`

> Centralized macOS environment configuration: app configs, shell setup, helper functions, and install/system scripts. This repo is the **source of truth**; most files are symlinked into the locations each app expects (`repo file ← system path`). See `setup_symlinks.sh` for the symlink wiring (it covers 5 of the 6 documented links — the nordvpn LaunchAgent plist is wired out-of-band; see `docs/install/bootstrap-flow.md`).
>
> **KEEP THIS CURRENT:** when you add, move, remove, or rename a file, or change a symlink target, update the matching entry here in the same change.

All prose/context documentation lives in `docs/`, subfoldered by area (`docs/window-manager/`, `docs/install/`, `docs/scripts/`). Read the relevant guide there before acting on a topic. Guides + reference notes belong in `docs/`; this index + AGENTS.md point into it.

```
configs/    app configs and portable settings (WM, vscode, iterm2, macOS)
docs/       prose context guides, subfoldered by area (window-manager, install, scripts)
zsh/        ~/.zshrc + sourced configs and aliases
scripts/    install/system scripts (installs/, git/, obsi)
functions/  shared SH helpers sourced by scripts
logs/       runtime logs (gitignored)
```

## configs
App configuration; the window-manager stack (aerospace + sketchybar + borders) is the most-edited area. Its authoritative guide is `docs/window-manager/guide-window-manager.md`.
- `configs/aerospace/aerospace.toml` — AeroSpace tiling WM config (workspaces, keybindings, gaps) — `← ~/.aerospace.toml`. Its three `after-startup-command`s launch sketchybar + borders, then run `apply-display-profile.sh` once the WM is up (regenerates the per-monitor top gaps + the workspace 7-9 assignment); the bar itself draws on the main monitor only (sketchybarrc `display=main`). Four `on-window-detected` float rules: CrossOver, Stickies, Preview (all by app-id) and one shared **CrossOver-games** rule by app-name regex (`(?i)ravenswatch|path ?of ?exile` — add new games there; CrossOver games run as bare Wine processes with a NULL bundle id, so app-id can't match them, and the boot-time CrossOver launcher reports a *different* name/id than the running game). *Edit when: changing window-manager keybindings/layout. Run `aerospace reload-config` after.*
- `configs/aerospace/` holds **no plist** — the WM stack has no LaunchAgent at all (AeroSpace starts at login via `start-at-login`; sketchybar/borders are spawned by its startup command).
- `configs/aerospace/*.sh` — WM helper scripts run by aerospace: `lib-paths.sh` (shared lib, below), `apply-display-profile.sh` (auto top-gaps **and** the workspace 7-9 monitor assignment — flips between `'built-in.*'` and `'secondary'` per which display is main, so home/travel both work; **runs only from aerospace.toml's startup command**, so re-profile after a monitor change = `aerospace-restart`), `open-dock-app.sh`.
- `configs/aerospace/lib-paths.sh` — shared library **sourced by `open-dock-app.sh`**: defines `PLACEMENT_CAP_SECONDS=18` (open-dock-app's placement-enforcer cap). *Edit when: changing any cross-script timing constant.* (The empty-workspace watcher/MRU/grace/`aero()` stack was removed 2026-07 — AeroSpace natively reveals the next focused window's workspace when the last window closes.)
- `configs/sketchybar/sketchybarrc` — status-bar entry point (sources colors/icons/theme, loads items + plugins; bar `display=main` — main monitor only, secondaries never draw it) — dir `← ~/.config/sketchybar`. *Edit when: changing the status bar.*
- `configs/sketchybar/colors.sh`, `icons.sh` — shared palette and icon glyphs. colors.sh's `BORDER_ACTIVE`/`PINK` (`0xffaa2222`) must stay in sync with `configs/borders/bordersrc` (its header says so).
- `configs/sketchybar/theme.sh` — **visual template / single source of truth** for "division" geometry (corner radius, border, blur, drop shadow, `GROUP_GAP` between divisions, plus `DIVISION_PAD`/`ELEMENT_GAP` for inner edge + element spacing). Sourced by sketchybarrc before items; every bracket on both sides pulls from these tokens. *Edit when: restyling the bar's overall pill/division look (radius, shadow, spacing).*
- `configs/sketchybar/helpers/wifi_rssi.swift` — tiny CoreWLAN Swift helper printing the current Wi-Fi link RSSI (no scan, no Location permission). plugins/wifi.sh compiles it on demand to the gitignored `helpers/wifi_rssi` binary for the strength icon (macOS 26 removed `airport`). *Edit when: changing what the helper reports.*
- `configs/sketchybar/helpers/wifi_rssi` — the **compiled** Swift binary (gitignored; should exist locally — plugins/wifi.sh builds it on first run).
- `configs/sketchybar/items/*.sh` — one bar item definition per file, BUT not all are wired. Live files include spaces, calendar, battery, ram, cpu, vpn (two items), ethernet, wifi; `apple.sh`/`settings.sh` are commented and `front_app.sh`/`brew.sh`/`github.sh`/`spotify.sh` are not sourced (6 inert template leftovers). The audio division (volume + headset) was removed entirely 2026-07 — its item/plugin files are deleted (icons.sh glyphs kept). Paddings come from theme.sh tokens. Right-side visual order is connectivity | resources | calendar. Several live items are state-driven: ethernet shows only when connected; vpn_be/vpn_sn = two text icons (**BE**/**SN**) for the two most-used native-IKEv2 NordVPN exits, **colour-only** (grey = not connected, red = connected, yellow = connecting, magenta = `nord refresh` needed) — no orange and no selection marker: both grey just means the VPN is off, and which country `nord on` would dial is deliberately not shown; click a grey icon = connect that country (`nord <cc>` switch+on, or `nord toggle` when it is already the selected one), click the red one = disconnect (`nord toggle`), with instant busy "…" on the clicked icon and one shared click lock; custom `vpn_change` event triggered by the `scripts/vpn/` stack; wifi = RSSI bars.
- `configs/sketchybar/plugins/*.sh` — update/event scripts backing the items; **the live plugin set is ~12** and remaining files are dead legacy template leftovers. Live + load-bearing: `icon_map.sh` (maps apps to sketchybar-app-font glyphs with full-name text fallback for unmapped apps, used by `aerospace.sh` for the spaces app icons), `aerospace.sh`, `date.sh`, `time.sh`, `wifi.sh` (RSSI strength icon), plus the per-item updaters (ethernet, ram, cpu, battery) and `vpn.sh` (paints BOTH vpn items from one vpnutil snapshot; label colour is the only channel) and `vpn_click.sh` (shared handler for both vpn icons: `$NAME` → cc, busy feedback + one shared click lock with an `owner` file → `nord <cc>` on the non-selected icon, `nord toggle` on the selected one). *Do not assume a plugin is dead just because it's old — icon_map/aerospace/date/time are live.*
- `configs/borders/bordersrc` — JankyBorders window-border config — dir `← ~/.config/borders`. `active_color=0xffaa2222` MUST stay in sync with colors.sh `BORDER_ACTIVE` (colors.sh's header literally says "keep in sync with configs/borders/bordersrc"). *Edit when: changing border colour/width/style — mirror the colour to colors.sh.*
- `configs/vscode/settings.json` — VS Code user settings — `← ~/Library/Application Support/Code/User/settings.json`.
- `configs/iterm2/com.googlecode.iterm2.plist` — iTerm2 prefs. Loaded via iTerm2's **"Load preferences from custom folder"** (a two-way LIVE file at `$APP_CONFIGS/iterm2` via `PrefsCustomFolder` + `LoadPrefsFromCustomFolder`, **NOT a symlink**), wired by `scripts/installs/install_iterm2.sh`. **Gotcha: iTerm2 must NOT be running when those defaults are written or it overwrites the plist on quit.** Installer stops while iTerm is running or process inspection fails so the human can transfer the active session, quit, and rerun. No Always save-back policy is set. (The `recolor` random-tab-color helper lives in `zsh/configs/iterm2.zsh`.)
- `configs/nordvpn/com.teazyou.nordvpn-native.plist` — native-NordVPN reconnect LaunchAgent (`← ~/Library/LaunchAgents/`, symlinked out-of-band, NOT in setup_symlinks.sh): `RunAtLoad` + `WatchPaths` on resolv.conf fire the one-shot `scripts/vpn/nord-connect.sh` on load/login and resolver-file changes (typically wake/network activity, not a guarantee for every event) — **no StartInterval, no KeepAlive, zero resident processes**. See `docs/vpn/guide-nordvpn-native.md`. *Edit when: changing what events trigger reconnection.*
- `configs/macos/preferences.json` — normalized current Finder/Dock values, six application pins (ChatGPT Desktop at position 4) plus Downloads, selected system shortcuts, and ABC as the sole desired input source. Existing destination input sources remain intact. Applied through `scripts/installs/apply_macos.swift`, never a native-plist symlink. No menu overrides were observed; Dictation and sidebar restoration remain manual. See the macOS guide.
- `configs/dot-obsidian/` — central Obsidian config (plugins, snippets, hotkeys, appearance, *.json settings). Not symlinked as a whole; the `obsi` launcher (`scripts/obsi`) plants per-file symlinks from each vault's `.obsidian/` to entries here (the per-file-symlink/BLACKLIST model is documented in `scripts/obsi`). Per-vault runtime state (workspace.json, workspace-mobile.json, graph.json, file-recovery/, cache/, .trash/, *.bak) is gitignored — see `.gitignore`.

## zsh
Shell setup; `zshrc.zsh` is the entry point that sources everything else.
- `zsh/zshrc.zsh` — `~/.zshrc` source-of-truth; sources every config + alias below — `← ~/.zshrc`. *Edit when: changing what loads at shell startup.*
- `zsh/configs/path.zsh` — exports the path vars used everywhere (`WORKSPACE`, `SCRIPTS`, `APP_CONFIGS`, `FUNCTIONS`, `KEYS_DKT`, `ZSH`, `ZSH_CONFIGS`/`ZSH_ALIAS`) initializes native Homebrew `shellenv`, and **prepends `~/.local/bin` (`PATH_CLAUDE`, the Claude CLI) to PATH**. *Edit when: adding a new sourced dir or PATH entry.*
- `zsh/configs/*.zsh` — startup configs: `colors.zsh`, `oh-my-zsh.zsh` (theme/plugins), `git.zsh` (writes `git config --global` core.editor/user.email/user.name on **every** shell startup), `nvm.zsh` (loads Homebrew’s `opt/nvm/nvm.sh`, matching installer; activates in a new shell after Node and links), `iterm2.zsh` (random per-tab colour + `recolor`).
- `zsh/alias/*.zsh` — alias groups by topic: `osx.zsh`, `navigation.zsh`, `obsidian.zsh` (the `obsi` vault launcher → `scripts/obsi`), `git.zsh`, `installations.zsh`, `claude.zsh` (the `sopaios` launcher → `scripts/claude/sopaios.sh`), `vpn.zsh` (the `nord` VPN CLI → `scripts/vpn/nord.sh`), `tiktoken.zsh` (the `tiktoken <file_path>` token counter → `scripts/tiktoken.sh`). **`git.zsh` also defines a `git()` function that reroutes every `git push` through `scripts/git/gpush.sh`** (plain `git push` is intercepted — see `docs/scripts/git-scripts.md`). *Edit when: adding a terminal alias.*

## scripts
Install, git, and system scripts. The fresh-Mac flow is documented in `docs/install/bootstrap-flow.md`; the Git workflow helpers in `docs/scripts/git-scripts.md`.
- `scripts/installs/bootstrap.sh` — phase-1 entry: finite CLT/platform checks, native Brew/Git, frozen published source/revision and safe checkout gate, minimum apps/native Claude CLI, verified artifacts, auth instructions and full concrete prompt, then STOP. No full installer. Ignores Git replacement objects during source verification; `--revision FULL_COMMIT_ID` supports an authorized immutable staging candidate.
- `scripts/installs/installation.sh` — explicit manual installer only; 13 scripts with Node before shell links, native Brew/CLI environment, no default maintenance, and honest manual-verification notices. Supervised recovery invokes scoped scripts instead. *Edit when: adding/removing an install step.*
- `scripts/installs/setup_symlinks.sh` — creates the repo→system symlinks, preserving wrong links and real targets in unique private `.bak.XXXXXX/original` backups. **NOT the full map: it creates only 5 of the 6 documented links** (the nordvpn LaunchAgent plist is wired out-of-band). *Edit when: adding/changing a symlink target — and update both this index and `docs/install/bootstrap-flow.md`.*
- `scripts/installs/install_*.sh` — one installer per tool/area (brew, node, claude, iterm2, vscode_ext, oh_my_zsh, touch_id_sudo, xcode_mas, window_manager). `install_claude.sh` verifies the Brew Desktop and separate sole native Claude Code CLI; `--cli-only` serves bootstrap; conflicting CLI distributions/executables stop for diagnosis. Explicit `--desktop-fallback` is a safe missing-app repair after Python, without replacement or quarantine stripping; a running app or indeterminate process check blocks that repair.
- `scripts/installs/install_brew.sh` — single install/list/verify inventory (`--phase minimal|remaining|all`, `--verify-only`, `--list`; default all). Minimal casks: `iterm2`, `chatgpt`, `claude`, `codex`, `brave-browser`. Remaining formulae: `python`, `nvm`, `sketchybar`, `borders`, `ripgrep`, `mas`, `gh`; remaining casks: `visual-studio-code`, `google-chrome`, `spotify`, `bitwarden`, `nikitabobko/tap/aerospace`, `font-hack-nerd-font`, `font-sketchybar-app-font`, `discord`, `obsidian`. Git is in bootstrap. Remaining/all adds `felixkratz/formulae`; no default cleanup/upgrade. `--maintenance` is separate manual work after safe session handoff. `claude` is Desktop, `codex` is CLI; native Claude Code is separate, no duplicate CLI distribution. Brave is application-only.
- `scripts/installs/recovery_checks.sh` — shared side-effect-free app/CLI readiness and single-guide prompt renderer; active header/contract validation rejects draft mentions and unresolved handoff fields.
- `scripts/installs/tests/test_supervised_recovery.py` — isolated package/artifact, source/checkout, prompt, interruption, shell-loader, and session-protection fixtures; no live system changes or lint.
- `scripts/installs/install_vscode_ext.sh` — exactly `bracketpaircolordlw.bracket-pair-color-dlw` and `chunsen.bracket-select`; the existing settings symlink stays.
- `scripts/installs/setup_macos.sh`, `apply_macos.swift` — manual stage 9: apply captured managed preferences with CFPreferences, private changed-key backups, and public TIS input enable/selection; retain existing keyboard/screenshots/dark-mode/save-panel/`.DS_Store` defaults and normal Finder/Dock restart. `scripts/installs/tests/test_macos_preferences.py` verifies isolated fixtures and mocked shell behavior.
- `scripts/installs/setup_wallpaper.sh` — solid-black wallpaper setup.
- `scripts/installs/setup_dev.sh` — stage 13: creates `~/dev` for the `dev` navigation function, preserving any existing projects. The `setup_dev` alias reruns this step.
- `scripts/installs/helper_prompt.sh` — `log_*` color/prompt helpers sourced by install scripts.
- `scripts/git/g*.sh` — git workflow helpers (`gcommit`, `gcreate`, `gdelete`, `gpush`, `gstatus`); fronted by `zsh/alias/git.zsh`. **`gpush.sh` is the transparent push wrapper** every `git push` routes through (cleans `.DS_Store`, status, real push via `command git push`, then per-repo cleanup + post-push hook). See `docs/scripts/git-scripts.md`.
- `scripts/claude/sopaios.sh` — `claude --plugin-dir <SOPAIOS working copy> "$@"` wrapper, so the plugin is loaded from disk (dev mode) instead of a cached install. Fronted by the `sopaios` terminal alias (`zsh/alias/claude.zsh`); plugin dir + claude binary overridable via `SOPAIOS_PLUGIN_DIR`/`SOPAIOS_CLAUDE_BIN`. *Edit when: changing the default plugin working copy or claude binary path.*
- `scripts/vpn/` — native NordVPN IKEv2 stack (authoritative guide: `docs/vpn/guide-nordvpn-native.md`): `nord.sh` (the `nord` CLI — switch country / on / off / toggle / status / list / refresh / rescue; strict single-slot stop→start sequencing + shared /tmp lock), `nord-connect.sh` (the LaunchAgent one-shot: event-driven reconnect of the saved country, no polling, 10-min per-network failure cooldown; **no boot reset — a reboot preserves the last country/on-off state**), `nord-gen-bundle.sh` (renders the 6-country + Root CA `.mobileconfig` from live Nord API best-server data; one manual approval per regeneration). Secrets/state live in `~/.config/nordvpn-native/` (0600), never in the repo. *Edit when: changing countries, reconnect behavior, or profile contents.*
- `scripts/aerospace-restart.sh` — full restart of the WM stack: `killall`s AeroSpace/sketchybar/borders, sleeps a beat, then `open -a AeroSpace` (its after-startup-command relaunches sketchybar + borders). Also the way to re-apply the per-monitor gaps + the workspace 7-9 assignment after plugging/unplugging a display; nothing else re-runs `apply-display-profile.sh`.
- `scripts/dstore.sh` — recursively delete both `.DS_Store` AND `_DS_Store` files; used by the git scripts (`silent` mode).
- `scripts/tiktoken.sh` — count UTF-8 file tokens with tiktoken's `o200k_base` encoding; fronted by the `tiktoken <file_path>` terminal alias in `zsh/alias/tiktoken.zsh`. Requires the Python `tiktoken` package.
- `scripts/obsi` — Obsidian vault launcher: opens a folder as a vault, planting per-file symlinks from its `.obsidian/` to the central `configs/dot-obsidian` config. Fronted by `zsh/alias/obsidian.zsh` (`obsi [folder]`). *Edit when: changing which central entries are shared (BLACKLIST) or the open mechanism.*

## functions
Shared SH helpers sourced by other scripts.
- `functions/brew.sh` — idempotent receipt/install/tap helpers, used only by `install_brew.sh`; failures propagate, no work at source time, missing targets show dry-run diagnostics. Package artifacts and aggregate failure checks belong to the caller.

## Optional / low-touch
- `logs/` — runtime output, gitignored except `.gitkeep`: `nordvpn-native.log` (VPN reconnect agent).
- `_HUMAN-only.md` — a gitignored root note (matched by the `_HUMAN-ONLY.md` rule in `.gitignore`, case-insensitive on APFS). Convention: files matching that rule are **human-only** scratch and are never committed.
- `.gitignore` — ignores `.DS_Store`/`._*`/`.vscode`, `*.bak`, `logs/*` (except `.gitkeep`), the `_HUMAN-ONLY.md` human-only rule. Plus two scoped blocks: the `configs/dot-obsidian/` per-vault runtime state (workspace.json, workspace-mobile.json, graph.json, file-recovery/, cache/, .trash/, *.bak); and the sketchybar machine-local artifact (`configs/sketchybar/helpers/wifi_rssi`). *(Per-config `.gitignore` files are not used; rules are consolidated here.)*
